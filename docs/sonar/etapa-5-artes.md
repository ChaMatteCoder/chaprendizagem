# Artes da Etapa 05

Criadas em 30/09/2026 com a ferramenta **image_gen integrada ao Codex**, sem API externa ou CLI. Referências fornecidas pelo usuário; imagens usadas como guias de estilo. As três saídas foram copiadas, sem alteração, para `public/images/sonar/`. Submarino e sprite têm canal alfa (canto transparente). Textos, controles, curvas, probabilidades e o marcador neutro são componentes HTML/CSS/React reais.

A tipografia de títulos reutiliza Lilita One já distribuída em `public/fonts/iadivinha/`; o escopo dos estilos pertence ao Sonar.

## Cenário

Arquivo: [ocean.png](../../public/images/sonar/ocean.png). Referência: menu `Imagem do ChatGPT 30 de set. de 2026, 10_45_37-1.png`.

Prompt final:

Create a NEW wide panoramic underwater illustrated background asset for a Portuguese educational sonar game, using the attached image only as a visual style reference. Rich polished hand-painted cartoon game art, deep midnight navy ocean, turquoise water and shafts of light from the upper right, reef rocks and aquatic foliage framing the far left/right edges and bottom, small warm coral orange accents, a few tiny distant fish silhouettes, subtle floating bubbles, soft textured shading and bold clean illustrated outlines. Main composition: keep the central 75 percent largely open calm dark blue water with ample negative space, especially the left half for real interface text. The bottom reef is a narrow decorative border. No submarine, no robot, no wreck, no main target object, no sonar waves; those will be separate interface elements. NO TEXT, letters, numbers, logos, buttons, cards, borders, UI, watermark, or question marks. Landscape approximately 16:9. High-quality cohesive artwork matching the friendly reference palette and illustrated ocean style, not photorealistic.

## Submarino

Arquivo: [submarine.png](../../public/images/sonar/submarine.png). Referência: mesmo menu. `transparent_background: true`.

Prompt final:

Generate a NEW isolated mascot illustration asset on a TRUE TRANSPARENT alpha background for an educational sonar game. Use the attached Portuguese game image only as the style and character design reference. One cute bright golden-yellow toy submarine facing RIGHT, horizontal side / three-quarter view, bold dark navy ink outlines, softly textured hand-painted cartoon shading, rounded capsule body, small propeller at the LEFT rear, periscope above, two small round turquoise side windows, large luminous turquoise round glass cabin at the RIGHT front with a friendly tiny teal robot pilot visible inside, simple smiling cyan face. Match the reference yellow submarine with robot, playful polished game art. Submarine only, centered with modest empty transparent margin, complete silhouette including all appendages, no cropping. No ocean, reef, bubbles, backdrop, rocks, target object, sonar waves, drop shadow, floor, text, lettering, numerals, UI, logo, or watermark. No solid-colored background. Wide horizontal sprite approximately 3:2.

## Ícones das escolhas

Arquivo: [choices.png](../../public/images/sonar/choices.png). Referência: missão `Imagem do ChatGPT 30 de set. de 2026, 10_45_38-2.png`. `transparent_background: true`. As duas metades são exibidas por posição do fundo CSS, sem editar a imagem. O objeto do contato só recebe esses ícones depois da revelação; antes, usa um círculo genérico com ponto de interrogação.

Prompt final:

Create a NEW two-icon sprite sheet on a TRUE TRANSPARENT alpha background for the choice buttons of an educational underwater game. Match the attached reference's polished friendly hand-painted cartoon illustration style: bold dark navy outlines, softly textured highlights and shadows. Wide landscape canvas ratio 2:1 containing exactly TWO separate centered objects, each occupying its own equal square half, with generous transparent space around them and a completely empty gap in the middle. LEFT half: one irregular rounded angular dark blue-gray stone with a few natural speckles, clearly a rock. RIGHT half: one clean silver steel cylinder lying horizontally diagonally with its round end facing lower left, curved silver surface and crisp white reflected bands. Both are large simple readable icons at the same visual scale. No submarine, robot, ocean, environment, sonar waves, drop shadows, floor, captions, letters, numerals, text, labels, UI, watermarks, borders, background color or gradients. Do not overlap the two objects or cross the center line. Full objects including edges, no cropping.
